# Валерій Копил — SEO-портфоліо

Опублікований сайт: https://kopylval189-ai.github.io/
Англійська версія: https://kopylval189-ai.github.io/en.html
Репозиторій: https://github.com/kopylval189-ai/kopylval189-ai.github.io

## Файли
- index.html — українська сторінка, стилі, інтерактивні блоки та посилання на документи.
- en.html — повний англійський переклад сторінки.
- logo.png — оригінальний логотип користувача. Темний фон узгоджено з сайтом через CSS; вихідне зображення не змінено.
- .nojekyll — вимикає обробку Jekyll.

Файли Valerii-Kopyl-CV.pdf, WebPromoExperts-certificate.pdf та certificate.jpg мають лежати поруч із HTML. PDF резюме та сертифіката залишаються українською, як зазначено біля документів. Перемикач UA / EN відкриває відповідну сторінку. Сайт не потребує Google-акаунта, сервера або сторонніх бібліотек.

## Оновлення
Завантажте змінені файли в корінь гілки main. GitHub Pages автоматично публікує її з /(root). Дочекайтеся завершення pages build and deployment у вкладці Actions.

Для локального перегляду відкрийте index.html або en.html, тримаючи logo.png і документи поруч. Старий Google Apps Script — окрема попередня версія; ці оновлення публікуються на GitHub Pages.
